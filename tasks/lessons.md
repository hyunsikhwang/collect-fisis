# Lessons

- Streamlit UI 개편에서 불필요한 설명 문구를 임의로 추가하지 않는다. 기존 기능 구조를 유지하되, 사용자가 요청한 미니멀 디자인에서는 헤더/메타/섹션 설명을 최대한 제거한다.
- 금융 대시보드 UI는 폰트, 간격, 탭 줄바꿈, 모바일 폭을 실제 렌더로 반드시 확인한다. 특히 탭은 줄바꿈이 생기지 않도록 nowrap/overflow 처리를 우선 적용한다.
- 사용자가 특정 폰트를 지정하면 CSS 최상위에 해당 폰트를 명시하고 모든 주요 Streamlit 컴포넌트에 상속되도록 강제한다.
- Streamlit Cloud를 유지해야 하는 앱에서는 React 전환을 해법으로 밀지 않는다. 대신 Streamlit 기본 위젯을 덜 노출하고, HTML/CSS로 통제 가능한 네비게이션과 밀도 있는 레이아웃을 우선 검토한다.
